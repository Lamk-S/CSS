Coloreando nuestra página

Guía de modelos de color, manejo de transparencias y aplicación práctica en CSS.

1. Modelos de color

En CSS podemos definir colores de varias formas dependiendo de lo que necesitemos:

  • Keywords (Palabras clave): Colores predefinidos como red, blue o transparent.
  • HEX (Hexadecimal): Sistema base 16, por ejemplo #FF0000.
  • RGB / RGBA: Basado en los canales Rojo, Verde y Azul. Ejemplo: rgb(255, 0, 0).
  • HSL / HSLA: Basado en Matiz, Saturación y Luminosidad. Muy útil para crear paletas consistentes.

2. Transparencia - Modelos vs Opacity

Existen dos formas principales de hacer que un elemento sea transparente o semitransparente, pero tienen comportamientos distintos:

a-. Usando el Canal Alfa (RGBA / HSLA / HEX con 8 dígitos)

Afecta solo al color que estamos definiendo (por ejemplo, el fondo), sin afectar a los elementos hijos (como el texto).

Fondo con transparencia (RGBA). ¡Mi texto se lee perfectamente!

b-. Usando la propiedad opacity

Afecta a todo el elemento y a sus hijos. Si le das opacidad a una caja, el texto dentro de ella también se volverá transparente.

Caja con Opacity. ¡Todo dentro de mí se vuelve transparente!

3. Aplicación de colores

Las principales propiedades de CSS para aplicar color son:

.elemento {
  color: #333333;
  background-color: hsl(200, 50%, 90%);
  border: 2px solid rgb(0, 100, 255);
}
