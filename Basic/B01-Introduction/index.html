Introducción a CSS

Apuntes breves con ejemplos de herencia, cascada y especificidad.

¿Qué es CSS y su sintaxis básica?

CSS (Cascading Style Sheets) es el lenguaje que define la presentación de documentos HTML. Su sintaxis básica:

selector {
  propiedad: valor;
  propiedad: valor;
}

Selectores de elementos, grupales, ID y Class

Los selectores nos permiten indicar a qué elementos HTML queremos aplicar estilos.

Selector grupal

Podemos agrupar varios selectores separándolos por comas para que compartan la misma regla:

h1, h2, h3, h4, h5, h6 {
  font-family: monospace;
  color: black;
}

ID y Clase

Selector de identificador (ID): Se usa para un elemento único en todo el HTML (no puede repetirse). Se referencia con #.

<!-- HTML -->
<div id="miIdentificador"></div>

/* CSS */
#miIdentificador { color: blue; }

Selector de clase (Class): Se usa para identificar uno o varios elementos. Se referencia con ..

<!-- HTML -->
<div class="miClase"></div>

/* CSS */
.miClase { color: blue; }

Características básicas

  • Todos los elementos tienen estilos por defecto del navegador (user agent styles).
  • Cascada: cuando hay conflicto, gana la regla que se aplica después (u otra más específica).
  • Especificidad: IDs > clases > etiquetas; inline > ID > clase > etiqueta (en general).
  • Herencia: propiedades como color o font-family se heredan de los ancestros.

Resultados de ejemplo

Soy un párrafo normal. Debe aparecer con la regla de párrafo (color azul y tamaño aumentado).

Soy un párrafo con id="miIdentificador". La regla por especificidad aplica aquí y me hace de otro color.

No soy un párrafo, soy un <div>. No tengo color explícito, así que heredo la tipografía y (si aplica) el color del ancestro.

Cómo usamos CSS en HTML

Preferir hojas externas y clases. Evitar estilos inline salvo para casos puntuales.

<!-- Inline (no recomendado) -->
<p style="color: blue;">Texto</p>

<!-- Externo (recomendado) -->
<p class="azul">Texto</p>
