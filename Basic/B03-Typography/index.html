Dominando la Tipografía

Guía completa sobre el manejo de fuentes locales, externas, tamaños accesibles y configuración de legibilidad en CSS.

1. Fuentes seguras de web (Web Safe Fonts)

Antes de descargar fuentes externas, debemos conocer las Web Safe Fonts. Son tipografías preinstaladas en la inmensa mayoría de sistemas operativos (Windows, macOS, Linux, Android).

Su mayor ventaja es el rendimiento: al no tener que descargar nada, la página carga instantáneamente. Siempre debemos incluirlas como "plan de respaldo" (fallback) en nuestra propiedad font-family.

  • Sans-serif (Sin remates): Arial, Helvetica, Verdana, Trebuchet MS. Dan un aspecto limpio y moderno.
  • Serif (Con remates): Times New Roman, Georgia, Garamond. Excelentes para textos largos y formales.
  • Monospace: Courier New, Consolas, Monaco. Todos los caracteres miden lo mismo de ancho; perfectas para mostrar código.
/* Ejemplo de un 'font stack' moderno de sistema */
body {
  font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}

2. Uso de fuentes locales con @font-face

Alojamos las fuentes en nuestro propio servidor (carpeta /fonts) para no depender de servicios externos y personalizar nuestro diseño al máximo. En este documento estamos cargando dos tipografías locales distintas:

  • Atkinson-hyperlegible: Cargada en formato .woff2. La hemos configurado para todo el texto base de la página por su alta legibilidad.
  • Grandstander: Cargada en formato .woff. La hemos aplicado a todos los encabezados (h1, h2, h3) para darle personalidad a los títulos.

Este texto está usando su variante Bold (Negrita).
¡Y esta caja muestra la fuente Grandstander en acción!

Así configuramos nuestros archivos en CSS:

@font-face {
  font-family: 'Atkinson-hyperlegible';
  src: url('../fonts/Atkinson-hyperlegible-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

4. Tamaño de la tipografía (Unidades)

Elegir la unidad correcta para font-size es crítico para la accesibilidad. Evitamos los píxeles para el texto principal porque impiden que el navegador escale la letra si el usuario tiene configurada una fuente más grande en su sistema.

  • px (Píxeles): Unidad estática. Útil para bordes o sombras, mala idea para texto.
  • em: Se basa en el tamaño del contenedor padre. Puede causar problemas si anidamos muchos elementos.
  • rem (Root em): Se basa en el tamaño raíz del documento (el html, que suele ser 16px). Es la unidad reina para textos. 1.5rem equivale a 24px si la raíz es 16px.

5. Configuración de párrafos y legibilidad

Una buena fuente no sirve de nada si el texto está amontonado. Para que el usuario no se fatigue al leer, controlamos tres factores principales en CSS:

  1. Interlineado (line-height): Espacio vertical entre líneas. Un valor entre 1.5 y 1.75 es ideal.
  2. Ancho de línea (max-width): Si una línea es muy larga, el ojo se pierde al volver al inicio. Usamos la unidad ch (caracteres) para limitarlo a ~65 caracteres.
  3. Alineación (text-align): En la web, justificar el texto (justify) suele crear "ríos blancos" horribles entre palabras. Es mejor alinear a la izquierda.
