Fondos, Enlaces y Pseudoclases

Guía para el manejo de fondos, decoraciones interactivas y estilización avanzada de elementos sin ensuciar el HTML.

1. Imágenes de fondo y repetición

La propiedad background-image permite colocar imágenes detrás del contenido. Por defecto, si la imagen es más pequeña que el contenedor, se repetirá infinitamente (en mosaico) para rellenarlo.

Controlamos este comportamiento con background-repeat:

  • repeat (por defecto)
  • repeat-x (solo horizontal) / repeat-y (solo vertical)
  • no-repeat (se muestra solo una vez)

2. Posición y Tamaño del Fondo

Cuando evitamos que la imagen se repita, podemos decirle exactamente dónde ubicarse y cómo ajustarse al contenedor.

  • background-position: Usa palabras clave (center, top right) o valores (50% 50%, 10px 20px).
  • background-size:
    • cover: Cubre todo el contenedor, recortando la imagen si es necesario, pero manteniendo la proporción. (Ideal para portadas).
    • contain: Escala la imagen para que se vea completa, aunque queden espacios vacíos.

3. Trabajando con más de una imagen

CSS permite apilar múltiples fondos en un solo elemento separándolos por comas. El primer fondo de la lista es el que estará "más arriba" (más cerca del usuario).

Esto es increíblemente útil para aplicar un gradiente oscuro semi-transparente sobre una fotografía para que el texto blanco sea legible.

4. Pseudoclases y Pseudoelementos

Nos permiten seleccionar estados específicos de un elemento o partes del mismo sin necesidad de agregar clases extra en el HTML.

Pseudoclases (El "Estado")

Seleccionan elementos según su estado de interacción o posición (ej: :hover, :focus, :active, :first-child).

Pseudoelementos (La "Estructura virtual")

Permiten insertar contenido virtual antes (::before) o después (::after) del contenido de un elemento, usando CSS. Requieren la propiedad content para funcionar.

5. Estilos y fondos en Enlaces

Los enlaces (<a>) interactúan mucho con las pseudoclases. El orden recomendado para definirlos en CSS es LoVe HAte (:link, :visited, :hover, :active).

Además, podemos usar background-image en un enlace para colocarle un pequeño ícono (muy común para indicar que es un enlace externo o de descarga).
