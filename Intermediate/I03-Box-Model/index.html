El Modelo de Caja (Box Model)

Comprende cómo los navegadores calculan el tamaño y el espaciado de cada elemento en la web. Todo en CSS es una caja.

1. ¿Qué es el Modelo de Caja?

En HTML y CSS, todo es una caja rectangular (incluso los textos o botones con bordes redondeados). El Modelo de Caja es el conjunto de reglas que define las partes de esa caja y cómo interactúan entre sí. Se compone de 4 capas, de adentro hacia afuera:

  1. Content (Contenido): El área donde se muestra el texto o la imagen.
  2. Padding (Relleno): Espacio transparente dentro de la caja, entre el contenido y el borde.
  3. Border (Borde): La línea visible que envuelve al padding y al contenido.
  4. Margin (Margen): Espacio transparente fuera de la caja, que la separa de otros elementos.

2. Márgenes y Paddings

Ambos generan espacio, pero de maneras totalmente distintas. El padding engorda el elemento por dentro (su fondo se expande), mientras que el margin empuja a los vecinos hacia afuera.

Podemos declararlos lado por lado (ej: margin-top, padding-left) o usando la propiedad abreviada (shorthand), que sigue el sentido de las agujas del reloj: Arriba, Derecha, Abajo, Izquierda.

/* Arriba: 10px | Derecha: 20px | Abajo: 15px | Izquierda: 5px */
padding: 10px 20px 15px 5px;

/* Arriba y Abajo: 2rem | Derecha e Izquierda: 1rem */
margin: 2rem 1rem;
Tengo padding: 2rem. Mi fondo azul crece.
Tengo margin: 2rem. Empujo a mis vecinos lejos de mí.

3. Borders (Bordes)

El borde envuelve el contenido y el padding. Para que un borde sea visible, necesita tres cosas: ancho, estilo y color.

También es aquí donde aplicamos el famoso border-radius para suavizar las esquinas.

4. La magia de Box-Sizing

Por defecto, CSS usa box-sizing: content-box. Esto significa que si le das a una caja un ancho del 100%, y luego le agregas padding o bordes, estos se sumarán al 100%, rompiendo el diseño y creando un scroll horizontal.

La solución moderna es usar box-sizing: border-box. Esto le dice a CSS: "Incluye el padding y el borde dentro del ancho que declaré". ¡Es un salvavidas absoluto!

Ambas cajas tienen: width: 100%; padding: 2rem; border: 5px solid;

content-box (Por defecto)
¡Me desbordo de mi contenedor! 100% + padding + border = 110%
border-box (La mejor práctica)
Me mantengo exactamente al 100%. CSS reduce el espacio del contenido para absorber el padding y el borde.
