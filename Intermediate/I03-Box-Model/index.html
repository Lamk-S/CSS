Módulo I03 · CSS Box Model & Sizing

El Modelo de Caja (Box Model)

Comprende cómo el motor de renderizado calcula las dimensiones y el espaciado de cada elemento en pantalla. Domina las cuatro capas concéntricas (content, padding, border, margin), el colapso de márgenes y el impacto decisivo de box-sizing: border-box.

1. Anatomía del Modelo de Caja

Para el motor de layout de CSS, todo elemento es una caja rectangular, incluso cuando visualmente tiene esquinas redondeadas o formas circulares. El Modelo de Caja gobierna el tamaño y la separación de cada caja mediante cuatro áreas concéntricas, de adentro hacia afuera:

  1. Content (Contenido): Área interior donde se renderiza el texto, imagen o elementos hijos. Sus dimensiones se controlan con width/height o inline-size/block-size.
  2. Padding (Relleno interior): Espacio transparente entre el contenido y el borde. Extiende el área clicable y el fondo (background) del elemento.
  3. Border (Borde): Trazo que envuelve al contenido y al relleno. Ocupa espacio físico dentro de la geometría de la caja.
  4. Margin (Margen exterior): Espacio transparente externo al borde que separa la caja de sus elementos vecinos. Nunca hereda el fondo del elemento.

2. padding vs margin y Colapso de Márgenes

Aunque ambos generan separación visual, operan en lados opuestos del borde: padding expande la caja hacia adentro (arrastrando su color de fondo), mientras que margin empuja a los elementos adyacentes hacia afuera.

Ambos aceptan la sintaxis abreviada (shorthand) en sentido horario: Arriba (Top) → Derecha (Right) → Abajo (Bottom) → Izquierda (Left). 

/* 4 valores: Top | Right | Bottom | Left */
padding: 12px 24px 16px 8px;

/* 2 valores: Vertical (Top/Bottom) | Horizontal (Left/Right) */
margin: 1.5rem auto; /* 'auto' en ejes horizontales centra bloques con ancho definido */

padding: 1.75rem (Espacio interno)

El fondo azul y el borde crecen hacia afuera para alojar el relleno interno.

Nota: En bloques verticales adyacentes, los márgenes se fusionan (margin collapsing) tomando el mayor de ambos en lugar de sumarse.

3. border y border-radius

Para que un borde se dibuje requiere tres subpropiedades: border-width (grosor), border-style (estilo de trazo, por defecto none) y border-color. Con border-radius redondeamos sus vértices; aplicar border-radius: 50% sobre una caja cuadrada produce un círculo perfecto.

4. box-sizing: content-box vs border-box

Por especificación histórica, CSS utiliza box-sizing: content-box. Bajo este modelo, width: 100% define únicamente el ancho del contenido, por lo que cualquier padding o border se suma por fuera y provoca desbordamiento horizontal.

Al declarar box-sizing: border-box, el navegador absorbe el padding y el border dentro del ancho total declarado, haciendo que los cálculos de maquetación sean exactos.

Comparativa directa: ambas cajas tienen width: 100%; padding: 1.5rem; border: 4px solid;

box-sizing: content-box (Comportamiento heredado)

Ancho real = 100% + 3rem (padding) + 8px (border). Sobrepasa la línea punteada que marca el límite del contenedor padre.

box-sizing: border-box (Estándar moderno)

Ancho real = exactamente 100%. El relleno y el borde se descuentan hacia el interior sin desbordar jamás.

/* Reset universal recomendado en todo proyecto CSS */
html {
  box-sizing: border-box;
}

*, *::before, *::after {
  box-sizing: inherit;
}
Regla de Oro en Producción

Incluye siempre box-sizing: border-box en el inicio de tu hoja de estilos. Evita el colapso inesperado de márgenes utilizando gap dentro de contenedores Flexbox o Grid para separar elementos hermanos.
