Posicionamiento en CSS

Aprende a sacar elementos del flujo normal del documento, moverlos en los ejes X, Y, Z, y crear componentes de interfaz avanzados.

1. Conceptos y Propiedades de Desplazamiento

Normalmente, el navegador pinta los elementos de arriba a abajo y de izquierda a derecha (el Flujo Normal). Cuando usamos la propiedad position, podemos alterar esto usando las propiedades de desplazamiento (offset):

  • top, right, bottom, left: Empujan el elemento en la dirección opuesta. Ej: top: 20px empuja el elemento 20px hacia abajo desde el borde superior.
  • Estas propiedades solo funcionan si el elemento tiene un position distinto a static.

2. Los Valores de 'Position'

a) Static (Por defecto)

El elemento sigue el flujo normal. Las propiedades top, left o z-index no tienen ningún efecto aquí.

b) Relative (Relativo)

El elemento se mueve en relación a su posición original. Deja un "fantasma" o espacio vacío donde solía estar, por lo que no afecta a los elementos vecinos.

2. Relative (top: 20px, left: 30px)

c) Absolute (Absoluto)

Saca al elemento completamente del flujo normal (sus vecinos actúan como si no existiera). Se posiciona en relación a su ancestro posicionado más cercano.

d) Fixed (Fijo)

Similar al absoluto, pero se posiciona en relación al Viewport (la pantalla). Si haces scroll en la página, el elemento fixed no se moverá. (Ej: Un botón flotante de chat).

e) Sticky (Pegajoso)

Actúa como relative hasta que haces scroll y cruzas un límite (ej: top: 0), momento en el que se vuelve fixed. Haz scroll en la caja de abajo para probarlo:

3. El Patrón Maestro: Padre Relativo + Hijo Absoluto

Este es el concepto que debes dominar. Si a un elemento hijo le pones position: absolute, buscará al primer ancestro que tenga position: relative para usarlo como su mapa de coordenadas. Si no encuentra ninguno, usará el límite de toda la página web.

4. Orden de Apilamiento (Z-Index)

Cuando los elementos se salen del flujo normal, pueden chocar o superponerse. La propiedad z-index controla la profundidad (el eje Z). Un número mayor significa que está más cerca del usuario (encima de los demás).

Nota: z-index solo funciona en elementos posicionados (relative, absolute, fixed, sticky).
