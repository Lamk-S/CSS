Posicionamiento en CSS

Controla cómo los elementos alteran o abandonan el flujo normal del documento mediante position, las propiedades de desplazamiento (top, right, bottom, left e inset) y el eje de profundidad z-index.

1. Propiedades de Desplazamiento (offset e inset)

En el flujo normal (Normal Flow), el navegador renderiza los bloques de arriba hacia abajo y los elementos en línea de izquierda a derecha. Al declarar un valor de position distinto de static, se activan cuatro coordenadas de desplazamiento más su propiedad abreviada moderna:

  • top, right, bottom, left: Definen la distancia desde cada borde del contexto de referencia hacia el interior. Por ejemplo, top: 16px desplaza la caja 16px hacia abajo desde el límite superior.
  • inset (Shorthand moderno): Permite declarar los cuatro lados en una sola instrucción (inset: 0; equivale a top: 0; right: 0; bottom: 0; left: 0;).
  • Regla de activación: Ninguna propiedad de desplazamiento ni z-index surte efecto mientras el elemento conserve position: static.

2. Los Cinco Valores de position

a) static (Valor por defecto)

El elemento sigue estrictamente el flujo normal del documento. Ignora top, right, bottom, left, inset y z-index.

b) relative (Relativo a su origen)

Desplaza visualmente el elemento respecto a su posición original en el flujo, pero conserva reservado su espacio original. Los elementos hermanos no se mueven para rellenar el hueco.

1. Static (Flujo normal)
2. Relative (top: 14px; left: 20px;)
3. Static (No sube a ocupar el espacio de 2)

c) absolute (Absoluto respecto a su ancestro posicionado)

Extrae el elemento por completo del flujo normal (no ocupa espacio y sus hermanos colapsan como si no existiera). Se posiciona respecto al ancestro más cercano con position distinto de static, o contra el bloque contenedor inicial si no existe ninguno.

d) fixed (Fijo respecto al Viewport)

Extrae el elemento del flujo y lo ancla a la ventana visible del navegador (viewport), permaneciendo inmóvil durante el scroll. Nota técnica: Si algún ancestro tiene transform, filter o perspective distinto de none, dicho ancestro pasa a actuar como marco de referencia en lugar de la pantalla.

e) sticky (Híbrido entre relative y fixed)

Comienza comportándose como relative dentro del flujo normal hasta que el desplazamiento alcanza el umbral declarado (ej. top: 0), momento en el que queda fijado dentro de los límites de su contenedor desplazable (overflow: auto / scroll).

Demo: Cabecera position: sticky; top: 0; dentro de un contenedor con scroll

Cabecera Sticky (top: 0) — Desplaza este panel ↓

1. Mientras el borde superior no toque top: 0, se comporta como relative.

2. Al alcanzar el límite superior del contenedor con overflow-y: auto, permanece anclado.

3. Si un ancestro padre tiene overflow: hidden sin altura definida, sticky dejará de funcionar.

4. Cuando el contenedor padre sale de pantalla, el elemento sticky se desplaza con él.

.sticky-header {
  position: sticky;
  top: 0;
  z-index: 10;
}

3. Patrón Maestro: Padre relative + Hijo absolute

Es uno de los patrones más utilizados en diseño de componentes UI (badges, botones de cierre, iconos dentro de inputs, overlays sobre tarjetas). Declarar position: relative en el contenedor padre (sin aplicar desplazamientos) establece un nuevo sistema local de coordenadas (0, 0) para sus hijos absolutos.

Nuevo · absolute

Tarjeta de Producto (position: relative)

Al establecer position: relative en esta tarjeta, la insignia roja con position: absolute; top: -12px; right: 16px; toma como referencia las esquinas de la tarjeta y no las de toda la ventana. 

.product-card {
  position: relative; /* Crea el contexto de coordenadas local */
}

.product-badge {
  position: absolute;
  top: -12px;
  right: 16px;
}

4. Orden de Apilamiento (z-index y Stacking Context)

Cuando múltiples elementos posicionados se superponen, z-index determina su orden en el eje Z (profundidad): valores enteros mayores se dibujan más cerca del usuario.

Trampa habitual (Contextos de Apilamiento): Un z-index: 9999 dentro de un padre que tiene z-index: 1 nunca podrá superponerse a otro bloque hermano que tenga z-index: 2, porque los hijos compiten únicamente dentro del contexto de apilamiento de su padre.

Buenas Prácticas en Producción

No uses position: absolute para construir la estructura general de una página (usa Flexbox o Grid). Reserva absolute para superposiciones puntuales, define una escala ordenada de variables CSS para tus capas (--z-dropdown: 100, --z-sticky: 200, --z-modal: 300) y utiliza el elemento nativo <dialog> cuando necesites renderizar en el Top Layer sin pelear con z-index.
