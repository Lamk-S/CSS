Módulo I02 · Document Flow & Classic Layouts

Diagramación en CSS (Layouts)

Fundamentos para controlar el flujo normal del documento: restricciones de tamaño seguro (max-width, min-height), comportamientos de visualización (display) y maquetación histórica con float y flow-root.

1. Control de Dimensiones: Estático vs Fluido

Fijar dimensiones rígidas con width y height suele provocar desbordamientos horizontales en pantallas estrechas o recortes cuando el texto crece. En diseño responsivo se priorizan las cotas mínimas y máximas.

  • width y height: Establecen dimensiones exactas y rígidas. Ignoran si el contenedor padre dispone de menos espacio.
  • max-width: Permite que el elemento se encoja fluidamente hasta el 100% de su padre, pero impide que crezca más allá del límite definido.
  • min-height: Garantiza una altura mínima estética, permitiendo que la caja crezca verticalmente si el contenido interno se expande.

Demo: Contenedor centrado con max-width: 420px

Esta caja declara width: 100%; max-width: 420px;. En escritorio se detiene en 420px; en móviles se adapta sin generar scroll horizontal.

.responsive-card {
  width: 100%;
  max-width: 420px;
  min-height: 120px;
  margin-inline: auto;
}

2. display, float y Contención de Flotantes

El flujo normal (Normal Flow) ubica los elementos según su propiedad display: los elementos block ocupan todo el ancho disponible apilándose verticalmente, mientras que los inline fluyen en línea con el texto ignorando width, height y márgenes verticales.

Comparativa de comportamientos de display

display: block (100% ancho, nueva línea) inline (solo contenido) inline-block (en línea + acepta dimensiones)

El mecanismo de float y el colapso del padre

Diseñado originalmente para envolver texto alrededor de imágenes editoriales, float: left o right extrae el elemento del flujo normal. Como el contenedor padre deja de calcular la altura de sus hijos flotantes, se requiere crear un Block Formatting Context (BFC) mediante display: flow-root (moderno) o la técnica .clearfix::after (clásica).

Demo: Texto envolviendo un bloque con float: left y display: flow-root

IMG
Float Left

Este párrafo fluye naturalmente alrededor de la caja flotante situada a la izquierda. Gracias a que el contenedor padre declara display: flow-root (la alternativa nativa sin pseudo-elementos al clásico hack clearfix), el borde y fondo del contenedor abrazan por completo la altura de la imagen sin colapsar. 

.float-container {
  display: flow-root; /* Crea un nuevo BFC: contiene hijos flotantes sin hacks */
}

/* Equivalente histórico para navegadores antiguos: */
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}

4. Diagramación por Columnas (Enfoque Mobile-First)

Antes de Flexbox y CSS Grid, las rejillas multicolumna se construían combinando box-sizing: border-box, anchos porcentuales (33.333%) y float: left. Aplicando arquitectura Mobile-First, las columnas se apilan al 100% en móviles y flotan lado a lado únicamente a partir de 768px.

Demo: Rejilla de 3 columnas con float + flow-root

Columna 1

width: 33.333% en escritorio; 100% en móvil.

Columna 2

box-sizing: border-box evita que el padding desborde el 100%.

Columna 3

Contenedor padre protegido con display: flow-root.

/* Mobile-First: apilado en pantallas pequeñas */
.col {
  width: 100%;
}

@media (min-width: 768px) {
  .col {
    float: left;
    width: 33.333%;
  }
}
Contexto Arquitectónico

En proyectos modernos, utiliza float únicamente para que el texto rodee imágenes dentro de artículos editoriales. Para construir sistemas de columnas, barras de navegación y alineaciones bidimensionales, utiliza Flexbox (Módulo I03) y CSS Grid (Módulo I04).
