Diagramación en CSS (Layouts)

Guía para controlar el flujo del documento: dimensiones, comportamientos de visualización (display) y maquetación tradicional con flotantes.

1. Ancho y Alto de las Cajas

Controlar las dimensiones es el primer paso para diagramar. No siempre queremos que una caja ocupe el 100% del espacio, ni que se rompa en pantallas pequeñas.

  • width y height: Definen el ancho y alto estático.
  • max-width y min-height: Son más seguros para el diseño responsivo. max-width: 100% asegura que una imagen o caja nunca desborde su contenedor.

Esta caja usa max-width: 400px;. En pantallas grandes no pasará de 400px, pero en celulares se encogerá fluidamente.

2. Display, Float y Clear

El comportamiento natural de los elementos web se define por su propiedad display. Los elementos en block ocupan toda la línea, mientras que los inline se ajustan a su contenido.

El uso de float

Originalmente creado para que el texto rodeara las imágenes (como en los periódicos). Al aplicar float: left o right, sacamos al elemento del flujo normal.

IMG Flotante

Este texto rodea a la caja flotante. Como la caja tiene float: left;, se alinea a la izquierda y permite que el contenido de texto suba y ocupe el espacio a su derecha. Es vital usar la técnica clearfix en el contenedor padre para evitar que su altura colapse cuando contiene elementos flotantes.

3. Diagramación por Filas

Es el flujo natural (normal flow) de los elementos de bloque (display: block). Se apilan uno debajo del otro de arriba hacia abajo. Ideal para la estructura principal: Cabecera, Contenido y Pie de página.

4. Diagramación por Columnas

Antes de la llegada de Flexbox y CSS Grid, la diagramación por columnas se lograba casi exclusivamente utilizando float y anchos en porcentajes (%).

Si queremos 3 columnas, les damos width: 33.33% y float: left a cada una.
