Flexbox en CSS

Domina el modelo de caja flexible: controla filas y columnas en una dimensión, alinea elementos sin hacks y construye componentes modernos como navbars y cards.

1. Que es Flexbox y cuándo usarlo

Flexbox es un modelo de layout unidimensional. Sirve para alinear elementos en una sola dirección: fila (horizontal) o columna (vertical). Es ideal para componentes como menus, barras de herramientas, grupos de botones o cards.

Se activa con display: flex en el contenedor padre. Todos los hijos directos se convierten en flex items.

  • Contenedor (flex container): El padre con display: flex
  • Items (flex items): Los hijos directos
  • Ejes: Main axis (principal) y Cross axis (cruzado). Dependen de flex-direction

2. Dirección de los ejes - flex-direction

Define cual es el main axis. Cambia completamente el flujo.

  • row (default): Izquierda a derecha
  • row-reverse: Derecha a izquierda
  • column: Arriba a abajo
  • column-reverse: Abajo a arriba

5. Envoltura y crecimiento - flex-wrap, flex-grow

Por defecto, Flexbox intenta meter todo en una sola línea. Con flex-wrap: wrap permitimos que salte de línea.

  • flex-wrap: nowrap (default) - todo en una línea, puede desbordar
  • flex-wrap: wrap - salta a la siguiente línea si no entra
  • flex-grow: cuanto crece un item para ocupar espacio sobrante
  • flex-shrink: cuanto se encoge si falta espacio
  • flex-basis: tamaño base antes de crecer/encogerse
  • Shorthand: flex: 1 equivale a flex-grow:1 flex-shrink:1 flex-basis:0%
