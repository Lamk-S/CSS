Módulo I05 · Flexible Box Layout

Flexbox en CSS

Domina el modelo de caja flexible unidimensional: controla la distribución de elementos a lo largo de los ejes Main y Cross, alinea sin hacks y construye componentes responsivos como barras de navegación y tarjetas adaptables.

1. ¿Qué es Flexbox y cuándo utilizarlo?

Flexible Box Layout (Flexbox) es un sistema de maquetación unidimensional diseñado para distribuir espacio y alinear elementos en una sola dirección a la vez: fila (horizontal) o columna (vertical). Es la herramienta óptima para barras de navegación, grupos de botones, controles de formulario y tarjetas con altura igualada.

Se activa declarando display: flex (o inline-flex) en el elemento padre, lo que convierte automáticamente a sus hijos directos en flex items.

  • Flex Container (Contenedor): El padre con display: flex que gobierna la dirección, el salto de línea y la alineación global.
  • Flex Items (Elementos): Los hijos directos del contenedor, que pueden crecer, encogerse o cambiar su alineación individual.
  • Main Axis y Cross Axis: El eje principal sigue la dirección definida por flex-direction; el eje cruzado siempre es perpendicular a él.

2. Dirección de los Ejes: flex-direction

Establece el sentido del Main Axis y, en consecuencia, rota automáticamente el Cross Axis a 90 grados.

  • row (Por defecto): Eje principal horizontal, de izquierda a derecha (en idiomas LTR).
  • row-reverse: Eje principal horizontal invertido, de derecha a izquierda.
  • column: Eje principal vertical, de arriba hacia abajo.
  • column-reverse: Eje principal vertical invertido, de abajo hacia arriba.

4. Alineación en el Cross Axis: align-items, align-self y gap

Mientras justify-content actúa sobre el eje principal, align-items alinea los ítems en el eje cruzado (verticalmente en una fila). Un ítem individual puede sobrescribir esa regla mediante align-self, y gap introduce separación limpia entre ítems sin márgenes laterales indeseados.

5. Envoltura y Flexibilidad: flex-wrap y flex

Por defecto, Flexbox intenta acomodar todos los hijos en una sola línea (nowrap), encogiéndolos si es necesario. Con flex-wrap: wrap permitimos que salten a nuevas líneas cuando falta espacio.

  • flex-grow: Factor de crecimiento proporcional para absorber espacio sobrante (por defecto 0).
  • flex-shrink: Factor de reducción cuando el espacio disponible es menor que la suma de bases (por defecto 1).
  • flex-basis: Tamaño inicial ideal del ítem antes de repartir espacio sobrante (por defecto auto).
  • Shorthand flex: 1: Equivale a flex: 1 1 0% (reparte el ancho en partes iguales ignorando el tamaño del contenido).

Flexbox vs CSS Grid

Utiliza Flexbox cuando el tamaño del contenido deba dictar cómo se distribuyen los elementos en una fila o columna (navbars, tags, toolbars). Utiliza CSS Grid (Módulo I06) cuando necesites alinear elementos simultáneamente en filas y columnas bajo una estructura estricta.
