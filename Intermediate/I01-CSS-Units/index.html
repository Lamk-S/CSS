Unidades de Medida en CSS

Guía técnica para dominar las unidades absolutas, relativas tipográficas (em, rem, ch) y del viewport (vw, vh, dvh), construyendo interfaces responsivas y respetuosas con las preferencias de accesibilidad del usuario.

1. Unidades Absolutas

Las unidades absolutas representan dimensiones fijas que no escalan según el contenedor ni según la configuración de tamaño de fuente del navegador. Son apropiadas para detalles estructurales finos como grosores de borde (1px) o desplazamientos de sombra, pero desaconsejables para tipografía o contenedores fluidos.

  • px (Píxeles CSS): Unidad de referencia en pantalla. Aunque un píxel CSS se mapea a múltiples píxeles físicos en pantallas Retina/HiDPI, su escala visual permanece rígida.
  • cm, mm, in, pt (Físicas): Centímetros, milímetros, pulgadas y puntos tipográficos. Reservadas casi exclusivamente para hojas de estilo de impresión (@media print).

Demo: Contenedor rígido con width: 300px

Esta caja mide exactamente 300px de ancho. Si el contenedor padre es más estrecho que 300px, provocará desbordamiento horizontal. 
.px-box {
  width: 300px; /* Dimensión fija: ignora el ancho disponible del padre */
}

2. Unidades Relativas Tipográficas (em, rem, ch)

Su valor final se calcula dinámicamente a partir de una referencia tipográfica. Son esenciales para la accesibilidad: si un usuario aumenta el tamaño de fuente predeterminado de su navegador de 16px a 20px, toda la interfaz construida con rem y em escala proporcionalmente.

  • em: Relativo al font-size del elemento padre (o del propio elemento cuando se usa en padding/margin). Si se anida en múltiples niveles, produce un crecimiento exponencial compuesto.
  • rem (Root em): Relativo exclusivamente al font-size del elemento raíz (<html>, por defecto 16px). Elimina el efecto compuesto y mantiene una escala predecible en toda la aplicación.
  • ch (Character): Equivale al ancho del glifo "0" en la fuente y tamaño activos. Es el estándar de oro para limitar el ancho de columnas de lectura entre 55ch y 70ch.

em anidado — Efecto compuesto (1.2em)

Padre: 1.2em (19.2px)
Hijo: 1.2em (23.04px)
Nieto: 1.2em (27.65px) 
/* 16px × 1.2 × 1.2 × 1.2 = 27.65px */
.em-level { font-size: 1.2em; }

rem anidado — Escala constante (1.2rem)

Padre: 1.2rem (19.2px)
Hijo: 1.2rem (19.2px)
Nieto: 1.2rem (19.2px) 
/* Siempre 16px × 1.2 = 19.2px */
.rem-level { font-size: 1.2rem; }

Demo: Medida óptima de lectura con max-width: 60ch

Este bloque limita su anchura máxima a 60ch. Independientemente de si la ventana mide 1000px o 1920px, cada línea mantiene entre 55 y 65 caracteres, evitando la fatiga visual al saltar de una línea a la siguiente.

3. Unidades del Viewport (vw, vh, dvh, vmin)

Las unidades de viewport calculan su tamaño como un porcentaje directo de las dimensiones de la ventana visible del navegador, permitiendo crear secciones de pantalla completa o proporciones fluidas sin JavaScript.

  • vw (Viewport Width): 1vw equivale al 1% del ancho total del viewport (incluyendo la barra de desplazamiento vertical si existe).
  • vh y dvh (Viewport Height): 100vh representa el alto clásico de pantalla; en navegadores móviles con barras de direcciones retráctiles, 100dvh (Dynamic Viewport Height) ajusta la altura en tiempo real sin recortar contenido inferior.
  • vmin / vmax: Evalúan el lado más corto o más largo de la pantalla, ideales para tipografía o figuras que deben conservar proporción tanto en vertical (portrait) como en horizontal (landscape).

Demo: Caja fluida basada en vw

Mi ancho es proporcional al viewport (50vw en escritorio). Redimensiona la ventana para observar el ajuste continuo. 
.hero-banner {
  min-height: 100dvh; /* Altura completa real en móvil y escritorio */
  width: min(90vw, 1200px);
}
Regla Práctica de Selección

Usa rem para tamaños de fuente y espaciados globales; em cuando quieras que el padding de un botón o icono escale proporcionalmente a su propio texto; ch para anchos de párrafos; y % / fr / dvh para estructuras de layout.
