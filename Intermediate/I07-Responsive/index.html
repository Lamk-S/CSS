Responsive Design y Media Queries

Diseña interfaces adaptables para móvil, tablet y escritorio. Domina la metodología Mobile-First, breakpoints basados en contenido, tipografía fluida con clamp() y Container Queries.

1. Qué es Responsive y Mobile-First

El diseño responsivo no consiste simplemente en "que se vea bien en el celular". Es una arquitectura donde el layout y los componentes se adaptan dinámicamente al espacio disponible desde una única base de código.

  • Mobile-First (Estándar moderno): Se escriben los estilos base para pantallas pequeñas (~320px) y se añade complejidad estructural mediante min-width. Reduce la sobrescritura de reglas CSS.
  • Desktop-First (Enfoque heredado): Parte de resoluciones de escritorio y oculta o reacomoda elementos usando max-width.
  • Viewport Meta Tag: Sin <meta name="viewport" content="width=device-width, initial-scale=1">, los dispositivos móviles simularán un ancho de ~980px y harán zoom out automático.
Principio de Arquitectura

Regla de oro: Empieza con una estructura lineal y ligera en móvil (1 columna, jerarquía tipográfica clara y áreas táctiles amplias) y enriquece la densidad visual progresivamente conforme crece el viewport.

2. Media Queries — Sintaxis y Breakpoints

Las Media Queries permiten aplicar bloques de CSS condicionalmente según las características del dispositivo o del área de visualización. 

/* 1. Estilos base (Mobile-First: 0px en adelante) */
.card {
  width: 100%;
}

/* 2. Tablet: a partir de 768px */
@media (min-width: 768px) {
  .card { width: 50%; }
}

/* 3. Desktop: a partir de 1024px */
@media (min-width: 1024px) {
  .card { width: 33.333%; }
}

/* Consulta por orientación del dispositivo */
@media (orientation: landscape) {
  /* Ajustes específicos para modo horizontal */
}

3. Unidades fluidas y clamp()

El CSS moderno permite crear interfaces elásticas que escalan de forma continua entre dos extremos sin necesidad de escribir múltiples saltos de @media.

Imágenes fluidas (100%)

IMG · max-width: 100% + height: auto
img {
  max-width: 100%;
  height: auto;
  display: block;
}

Tipografía fluida con clamp()

Título fluido sin saltos

.fluid-text {
  /* clamp(mínimo, ideal, máximo) */
  font-size: clamp(1.5rem, 3.5vw + 0.5rem, 2.75rem);
}

C. Container Queries — Responsividad a nivel de componente

A diferencia de las Media Queries (que miran el tamaño de toda la pantalla), las Container Queries permiten que un componente se adapte al ancho de su contenedor padre. 

.card-container {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .cq-card { flex-direction: row; }
}
