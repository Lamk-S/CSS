Transiciones, Transformaciones y Animaciones

Diseña micro-interacciones fluidas a 60fps sin JavaScript. Domina transition (interpolación entre estados), transform (composición acelerada por GPU) y secuencias multi-etapa con @keyframes.

1. Transiciones — Interpolación Suave de A a B

Las transiciones permiten que un cambio de valor en una propiedad CSS ocurra de forma gradual durante un intervalo de tiempo en lugar de aplicarse en un único fotograma.

  • transition-property: Define qué propiedad o propiedades serán observadas (evita all en producción para no animar propiedades costosas por accidente).
  • transition-duration: Tiempo total de la interpolación (ej. 220ms o 0.25s).
  • transition-timing-function: Curva matemática de aceleración (ease, linear, ease-in-out, cubic-bezier()).
  • transition-delay: Tiempo de espera antes de iniciar la transición.
  • Shorthand: transition: property duration timing-function delay;

Micro-interacción en botón (:hover, :focus-visible y :active)

.btn {
  background-color: #2563eb;
  /* Declara explícitamente qué propiedades transicionan */
  transition:
    background-color 0.25s ease,
    transform 0.2s cubic-bezier(0.34, 1.56, 0.64, 1),
    box-shadow 0.25s ease;
}

.btn:hover {
  background-color: #1d4ed8;
  transform: translateY(-2px);
}

3. Animaciones Continuas con @keyframes

Mientras que transition requiere un cambio de estado disparador (como :hover), las animaciones con @keyframes definen múltiples fotogramas clave y pueden ejecutarse automáticamente o en bucle infinito. 

@keyframes flotar {
  0%   { transform: translateY(4px); }
  100% { transform: translateY(-10px); }
}

.elemento {
  /* nombre | duración | curva | retardo | iteraciones | dirección */
  animation: flotar 1.1s ease-in-out 0s infinite alternate;
}

4. Rendimiento (60fps) y Accesibilidad

Para mantener una tasa constante de 60 cuadros por segundo (menos de 16.6ms por frame), anima únicamente propiedades resueltas en la capa de composición (GPU) sin recalcular geometría.

    animation-duration: 0.01ms !important;

Estándar UI/UX & A11y

El movimiento debe tener propósito: Las animaciones en interfaces profesionales guían la atención del usuario y confirman acciones (feedback); nunca deben bloquear la interacción ni superar los 300ms en controles cotidianos.
