Transiciones, Transformaciones y Animaciones

Diseña micro-interacciones fluidas a 60fps sin JavaScript. Domina transition (interpolación de estados), transform (composición en GPU) y secuencias complejas con @keyframes.

1. Transiciones — Interpolación suave de A a B

Las transiciones permiten que un cambio de propiedad CSS ocurra de forma gradual durante un intervalo de tiempo en lugar de aplicarse instantáneamente.

  • transition-property: Define qué propiedad o propiedades serán observadas (evita all en producción).
  • transition-duration: Tiempo que tarda en completarse la interpolación (ej. 250ms o 0.3s).
  • transition-timing-function: Curva de aceleración (ease, linear, ease-in-out, cubic-bezier()).
  • Shorthand: transition: property duration timing-function delay;

Micro-interacción en botón (Hover & Active)

.btn {
  background: #2563eb;
  /* Buena práctica: declarar explícitamente qué propiedades transicionan */
  transition: background-color 0.25s ease, transform 0.2s ease, box-shadow 0.25s ease;
}

.btn:hover {
  background: #1d4ed8;
  transform: translateY(-2px);
}

3. Animaciones continuas con @keyframes

Mientras que transition requiere un disparador (como :hover), las animaciones con @keyframes permiten definir múltiples etapas intermedias y ejecutarse automáticamente o en bucle. 

@keyframes flotar {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-16px); }
  100% { transform: translateY(0); }
}

.elemento {
  /* nombre | duración | curva | retardo | iteraciones | dirección */
  animation: flotar 1.2s ease-in-out 0.2s infinite alternate;
}

4. Rendimiento (60fps) y Accesibilidad

Para mantener una tasa constante de 60 cuadros por segundo (menos de 16.6ms por frame), anima únicamente propiedades gestionadas por la capa de composición del navegador.

Bajo costo (GPU / Composite) Alto costo (CPU / Reflow & Repaint)
transform (translate, scale, rotate) width, height, padding, margin
opacity top, left, right, bottom 
/* Accesibilidad obligatoria: respeta la configuración del sistema operativo del usuario */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
Estándar UI/UX & A11y

El movimiento debe tener propósito: Las animaciones en interfaces profesionales guían la atención del usuario y confirman acciones (feedback), nunca deben bloquear la interacción ni superar los 300ms en controles cotidianos.
