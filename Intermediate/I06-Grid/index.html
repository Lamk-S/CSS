CSS Grid Layout

El sistema de layout bidimensional mas potente de CSS. Crea grillas complejas, layouts tipo revista y estructuras responsive sin media queries con una sola línea.

1. Que es Grid y diferencia con Flexbox

Flexbox es unidimensional (una fila O una columna). Grid es bidimensional (filas Y columnas al mismo tiempo). Grid es para el layout macro de la pagina, Flexbox para componentes internos.

  • display: grid activa la grilla en el contenedor
  • Define columnas con grid-template-columns y filas con grid-template-rows
  • El espacio entre celdas se controla con gap

2. Unidades magicas: fr, repeat() y minmax()

La unidad fr (fraction) reparte el espacio sobrante. Es la clave para layouts flexibles sin calcular porcentajes.

  • 1fr 1fr 1fr = 3 columnas iguales
  • repeat(3, 1fr) = lo mismo, mas corto
  • 200px 1fr = sidebar fijo de 200px + contenido flexible
  • minmax(200px, 1fr) = minimo 200px, maximo flexible
  • repeat(auto-fit, minmax(250px, 1fr)) = responsive sin media queries

Grid Template Áreas - Layout visual con palabras

Nombras áreas y las dibujas como un ASCII art. Es el método mas legible para layouts grandes.

header
sidebar
main
footer
.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

4. Alineación en Grid

Grid tiene dos niveles de alineación: dentro de la celda y de la grilla completa.

  • justify-items / align-items: alineación de items dentro de su celda
  • justify-content / align-content: alineación de toda la grilla cuando es mas pequeña que el contenedor
  • place-items: center: shorthand para centrar todo (justify + align)
