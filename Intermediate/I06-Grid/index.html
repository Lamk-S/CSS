CSS Grid Layout

Domina el sistema de maquetación bidimensional nativo de CSS: organiza filas y columnas simultáneamente, crea rejillas responsivas sin media queries y diseña estructuras complejas mediante áreas nombradas.

1. ¿Qué es CSS Grid y en qué se diferencia de Flexbox?

Mientras Flexbox es unidimensional (controla una fila o una columna a la vez), CSS Grid es bidimensional: gobierna filas y columnas simultáneamente. Como regla general, Grid define la arquitectura macro de la página o sección, y Flexbox alinea los componentes internos.

  • display: grid: Convierte el elemento en un Grid Container y a sus hijos directos en Grid Items.
  • grid-template-columns y grid-template-rows: Definen las pistas (tracks) explícitas verticales y horizontales.
  • gap (row-gap / column-gap): Establece el espaciado interno entre celdas sin afectar los bordes exteriores.

2. Herramientas Clave: fr, repeat() y minmax()

La unidad fraccionaria fr distribuye el espacio libre disponible tras descontar pistas fijas y gap, evitando cálculos manuales de porcentajes.

  • repeat(3, 1fr): Sintaxis abreviada equivalente a 1fr 1fr 1fr.
  • 180px 1fr 1fr: Combina columnas de ancho fijo con columnas elásticas.
  • minmax(min, max): Define un rango seguro de tamaño (ej. minmax(0, 1fr) evita que textos largos desborden una columna flexible).
  • auto-fit vs auto-fill: Ambos generan tantas columnas como quepan; auto-fit colapsa las pistas vacías para estirar los ítems existentes, mientras auto-fill conserva el espacio de las pistas vacías.

Cada línea divisoria de la grilla está numerada (empezando en 1 desde el inicio y en -1 desde el final). Puedes expandir celdas con span o asignar nombres semánticos mediante grid-template-areas.

grid-template-areas — Arquitectura visual declarativa

Permite dibujar la estructura del layout como una matriz textual legible. Cada cadena representa una fila y cada palabra una celda.

header
sidebar
main
footer
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 0.75rem;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

4. Alineación en Grid (Celda vs Grilla Completa)

CSS Grid distingue entre alinear los ítems dentro de sus celdas y alinear el conjunto de pistas dentro del contenedor:

  • justify-items / align-items: Alinea el contenido dentro de cada celda (en eje horizontal y vertical).
  • justify-content / align-content: Alinea toda la rejilla cuando el tamaño total de sus pistas es menor que el contenedor.
  • place-items: center: Propiedad abreviada de align-items: center + justify-items: center.

Consejo de Arquitectura

Usa minmax(0, 1fr) en lugar de 1fr cuando tus celdas contengan bloques de código, tablas o textos largos sin espacios: por defecto, 1fr equivale a minmax(auto, 1fr) y permite que el contenido estire la columna por encima del ancho esperado.
