Módulo A08 · Native UI + @starting-style + Scroll Snap

Diálogos Nativos, @starting-style y Scroll Snap

Tres capacidades históricas que antes obligaban a instalar librerías de JavaScript ahora son nativas en CSS y HTML: carruseles con física magnética mediante Scroll Snap, modales accesibles en el Top Layer con <dialog> y animaciones desde display: none o hacia height: auto con @starting-style e interpolate-size.

1. CSS Scroll Snap — Carruseles e inercia magnética nativa

CSS Scroll Snap permite controlar dónde se detiene el desplazamiento de un contenedor tras soltar el gesto táctil o la rueda del ratón. Al delegar la física al compositor del navegador, el deslizamiento conserva la aceleración nativa del sistema operativo sin cálculos de coordenadas en JavaScript.

Propiedades en el contenedor vs en los ítems

/* Contenedor desplazable (Track) */
.carousel-track {
  display: grid;
  grid-auto-flow: column;
  grid-auto-columns: min(82%, 320px);
  gap: 1rem;
  overflow-x: auto;
  scroll-snap-type: x mandatory; /* Eje + rigor de enganche */
  scroll-padding-inline: 1rem;   /* Margen interno de seguridad al alinear */
  overscroll-behavior-x: contain;/* Evita navegar atrás/adelante al llegar al borde */
}

/* Cada tarjeta dentro del carrusel */
.carousel-slide {
  scroll-snap-align: center;     /* start | center | end */
  scroll-snap-stop: always;      /* Obliga a detenerse en cada slide al deslizar rápido */
}
Propiedad Valores clave Efecto en la experiencia de usuario
scroll-snap-type x mandatory / y proximity mandatory fuerza siempre el anclaje al soltar; proximity solo engancha si el ítem queda cerca del borde.
scroll-snap-align start, center, end Define qué punto del ítem se alinea con el punto de captura del contenedor.
scroll-snap-stop normal / always always impide que un gesto rápido salte 3 o 4 tarjetas de golpe (ideal para onboarding o galerías).
scroll-padding 1rem / 80px 0 0 Compensa el espacio de cabeceras fijas (sticky) o padding lateral para que el ítem no quede recortado.

2. <dialog> nativo + @starting-style — Modales sin librerías

El elemento HTML <dialog> abierto con .showModal() vive en el Top Layer del navegador (por encima de cualquier z-index), gestiona automáticamente la tecla Esc, bloquea la interacción con el fondo (inert) y estiliza el velo trasero mediante ::backdrop.

Históricamente, animar la apertura y cierre de un modal era difícil porque pasaba de display: none a display: block. Con @starting-style y transition-behavior: allow-discrete puedes animar tanto la entrada como la salida en CSS puro.

Ciclo completo de entrada y salida de un <dialog>

dialog.native-modal {
  opacity: 0;
  transform: translateY(16px) scale(0.96);
  transition:
    opacity 260ms ease,
    transform 260ms cubic-bezier(0.22, 1, 0.36, 1),
    overlay 260ms allow-discrete,
    display 260ms allow-discrete;
}

/* Estado abierto */
dialog.native-modal[open] {
  opacity: 1;
  transform: translateY(0) scale(1);
}

/* Fotograma 0 justo al pasar de display: none a display: block */
@starting-style {
  dialog.native-modal[open] {
    opacity: 0;
    transform: translateY(16px) scale(0.96);
  }
}

/* Velo del Top Layer */
dialog.native-modal::backdrop {
  background: rgba(15, 23, 42, 0);
  backdrop-filter: blur(0px);
  transition: background-color 260ms ease, backdrop-filter 260ms ease, overlay 260ms allow-discrete, display 260ms allow-discrete;
}

dialog.native-modal[open]::backdrop {
  background: rgba(15, 23, 42, 0.55);
  backdrop-filter: blur(4px);
}

@starting-style {
  dialog.native-modal[open]::backdrop {
    background: rgba(15, 23, 42, 0);
    backdrop-filter: blur(0px);
  }
}
Prueba cerrarlo con el botón, haciendo clic en el backdrop o pulsando Esc.

3. Acordeones nativos hacia height: auto — interpolate-size y Grid

Animar un elemento desplegable desde height: 0 hasta su altura intrínseca (height: auto) fue durante años uno de los mayores retos de CSS. Hoy disponemos de dos técnicas limpias: interpolate-size: allow-keywords sobre <details>::details-content y la técnica universal con CSS Grid (grid-template-rows: 0fr → 1fr).

Dos estrategias modernas sin medir scrollHeight en JS

/* Estrategia 1 (Estándar moderno): interpolación directa de keywords */
:root {
  interpolate-size: allow-keywords;
}

details.faq-item::details-content {
  block-size: 0;
  overflow-y: clip;
  transition: block-size 280ms ease, content-visibility 280ms allow-discrete;
}

details.faq-item[open]::details-content {
  block-size: auto;
}
¿Por qué <dialog> supera a un <div class="modal"> tradicional?

Porque utiliza el Top Layer nativo del navegador: nunca queda atrapado dentro de un contenedor padre con overflow: hidden, transform o z-index inferior, y gestiona automáticamente la accesibilidad de teclado y cierre con Esc.

¿Qué hace exactamente transition-behavior: allow-discrete?

Permite que propiedades discretas (como display o overlay) esperen a que finalice la transición de opacidad y escala antes de cambiar a display: none, evitando que el modal desaparezca de golpe al cerrarse.

¿Cómo funciona el fallback universal con Grid (0fr → 1fr)?

En navegadores que aún no soportan interpolate-size, envolver el contenido en un contenedor con display: grid; grid-template-rows: 0fr; transition: grid-template-rows 280ms ease; y cambiar a 1fr al abrir logra una transición fluida hacia altura automática con soporte universal.
