Performance y Rendering

El motor CSS no solo pinta píxeles: decide cuánto trabajo computacional realiza el navegador. Con content-visibility y contain omites el renderizado fuera de pantalla, con will-change preparas capas GPU bajo demanda, y con text-wrap equilibras titulares sin JavaScript.

1. content-visibility — Renderizado bajo demanda

Por defecto, el navegador calcula estilos, layout y paint de todo el árbol DOM inicial, incluso de miles de nodos que están muy por debajo del viewport. content-visibility: auto instruye al motor a omitir el renderizado de los elementos fuera de pantalla conservando su espacio reservado.

Sintaxis recomendada para listas, feeds y catálogos extensos

.feed-card {
  content-visibility: auto;
  /* Reserva altura estimada y recuerda la real tras el primer renderizado */
  contain-intrinsic-size: auto 74px;
}

Regla clave: Acompaña siempre content-visibility: auto con contain-intrinsic-size. Sin un tamaño intrínseco de reserva, la barra de desplazamiento (scrollbar) saltará bruscamente al hacer scroll conforme entren nuevos elementos.

Valores de content-visibility y casos de uso

Valor Comportamiento y uso Consideración técnica
auto Omite layout y paint fuera del viewport + margen de proximidad. Ideal para listas largas y artículos extensos. Requiere contain-intrinsic-size bien calibrado para evitar saltos de scroll.
hidden Omite el renderizado por completo manteniendo el estado interno del DOM (útil en pestañas o paneles inactivos). No es alcanzable por foco ni búsqueda en página (Ctrl+F) hasta volver a visible.
visible Comportamiento por defecto: renderiza todo el sub-árbol inmediatamente. Alto coste inicial en árboles con más de 1,000 nodos complejos.

2. contain — Aislamiento del ciclo de renderizado

La propiedad contain establece un contrato con el motor de renderizado: garantiza que las mutaciones internas de un componente no alterarán el flujo ni el pintado del resto del documento.

Niveles de contención y shorthands

/* Aislamiento estándar para componentes independientes */
.component {
  contain: content; /* Equivale a: layout paint style */
}

/* Aislamiento total para widgets o contenedores de dimensiones fijas */
.widget {
  contain: strict;  /* Equivale a: size layout paint style */
  height: 240px;
}
layout

Aísla el Layout

Los cambios internos no disparan un reflow global en elementos hermanos o ancestros.

paint

Aísla el Paint

Los descendientes no se dibujan fuera de los límites de la caja, creando un contexto de apilamiento y recorte.

size

Aísla el Tamaño

Las dimensiones del contenedor no dependen de sus hijos. Exige definir ancho/alto explícito para no colapsar a 0px.

3. will-change — Promoción controlada a capa GPU

will-change es una pista de optimización previa: advierte al navegador que una propiedad va a cambiar de forma inminente para que prepare una capa de composición en GPU. Aplicarlo de forma masiva satura la memoria de vídeo (VRAM) y degrada los tiempos de carga.

Uso correcto frente a anti-patrón global

Anti-patrón — Promoción global permanente 
/* NUNCA hacer esto */
* {
  will-change: transform, opacity;
}

Fuerza cientos de texturas persistentes en GPU, disparando el consumo de memoria y retrasando el primer pintado.

Correcto — Activación previa a la interacción 
.card {
  transition: transform 180ms ease;
}

.card:hover,
.card:focus-visible {
  will-change: transform;
  transform: translateY(-3px);
}

La capa se asigna justo al iniciar la interacción y el navegador la libera automáticamente al finalizar.

Regla de Oro en Composición GPU

Anima exclusivamente propiedades de composición (transform y opacity) y reserva will-change para estados previos a la animación o secuencias complejas donde detectes caídas de fotogramas en el panel Performance.

4. text-wrap — Tipografía equilibrada sin huérfanas

Las palabras sueltas al final de un titular (viudas o huérfanas) rompen la jerarquía visual. text-wrap: balance y text-wrap: pretty resuelven el salto de línea de forma nativa sin insertar &nbsp; ni scripts.

Default — text-wrap: wrap

Curso avanzado de CSS moderno con arquitectura escalable para sistemas empresariales

Flujo estándar: puede dejar una sola palabra suelta en la última línea.

Titulares — text-wrap: balance

Curso avanzado de CSS moderno con arquitectura escalable para sistemas empresariales

Iguala el ancho de cada línea. Ideal para encabezados cortos (hasta 6 líneas).

Párrafos — text-wrap: pretty

Al redactar párrafos largos, el algoritmo de ajuste evalúa las últimas líneas del bloque para evitar que una palabra quede aislada al final.

Optimizado para cuerpos de texto sin penalizar el rendimiento en bloques extensos.

h1, h2, h3 {
  text-wrap: balance; /* Equilibra titulares y encabezados */
}

p, li {
  text-wrap: pretty;  /* Evita palabras huérfanas al final de párrafos */
}
