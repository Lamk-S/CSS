Subgrid + Anchor Positioning

Resuelve dos limitaciones históricas del layout web: subgrid permite que los contenedores hijos hereden los tracks de su padre para alinear contenido interno, y anchor-name + position-area posicionan tooltips, menús y popovers anclados sin calcular coordenadas en JavaScript.

1. CSS subgrid — Herencia de tracks entre niveles

En CSS Grid tradicional, cada grilla anidada crea sus propios tracks independientes. Si tienes tres tarjetas con título, descripción y botón, los botones se desalinean cuando el contenido varía de altura. Con grid-template-rows: subgrid, el hijo adopta exactamente las líneas de la grilla padre. 

/* 1. El padre define la estructura de filas */
.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  grid-template-rows: auto 1fr auto; /* Título, cuerpo flexible, footer */
  gap: 1.25rem;
}

/* 2. Cada tarjeta abarca 3 filas del padre y hereda sus tracks */
.card {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
}

/* Ahora h3, p y button comparten alineación horizontal en todas las tarjetas */

2. Anchor Positioning — Tooltips y Popovers sin JS

Tradicionalmente, posicionar un elemento flotante respecto a un botón exigía medir coordenadas con getBoundingClientRect() y escuchar eventos de scroll y resize. Con CSS Anchor Positioning, vinculas ambos elementos de forma declarativa mediante un identificador de ancla.

Sintaxis moderna: anchor-name + position-area

/* 1. Definir el elemento disparador como ancla */
.trigger {
  anchor-name: --my-anchor;
}

/* 2. Vincular el elemento flotante y ubicarlo en la cuadrícula del ancla */
.tooltip {
  position: fixed;
  position-anchor: --my-anchor;
  position-area: bottom center;
  margin-top: 8px;

  /* Si se acerca al borde del viewport, invierte eje bloque o en línea */
  position-try-fallbacks: flip-block, flip-inline;
}

Demo 3: Popover API (HTML) + Anchor Positioning (CSS)

La combinación estándar recomendada: el atributo nativo popover gestiona la Top Layer, el cierre con Esc y clic exterior, mientras CSS lo ancla al disparador.

Popover anclado sin JavaScript

Renderizado en la Top Layer del navegador, anclado mediante position-anchor: --anchor3 y con inversión automática ante bordes de pantalla.

#anchor3 { anchor-name: --anchor3; }

#my-popover {
  position-anchor: --anchor3;
  position-area: bottom center;
  position-try-fallbacks: flip-block, flip-inline;
  margin-top: 8px;
}
Regla de Oro en Anchor Positioning

Incluye siempre position-try-fallbacks: flip-block, flip-inline; en tus elementos flotantes. Si el usuario abre un menú cerca del borde inferior o lateral de la ventana, el motor recalcula la posición en el eje opuesto de forma nativa, reemplazando dependencias externas como Floating UI o Popper.js.

4. Soporte en Navegadores y Estrategia de Fallback

  • CSS Subgrid: Soporte completo en todos los navegadores modernos (Chrome 117+, Edge 117+, Firefox 71+, Safari 16+). En navegadores antiguos degrada de forma natural a una grilla estándar sin romper el contenido.
  • Popover API: Parte de CSS/HTML Baseline con soporte nativo multi-navegador.
  • Anchor Positioning: Disponible en Chromium (Chrome/Edge 125+) y Safari moderno. Utiliza @supports not (position-anchor: --x) para ofrecer posicionamiento clásico position: absolute como respaldo progresivo. 
@supports not (position-anchor: --a) {
  .tooltip {
    position: absolute;
    bottom: calc(100% + 8px);
    left: 50%;
    transform: translateX(-50%);
  }
}
