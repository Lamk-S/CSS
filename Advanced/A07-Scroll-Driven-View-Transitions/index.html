Módulo A07 · Scroll-Driven + View Transitions + @property

Animaciones de Nueva Generación

Antes animabas únicamente en función del tiempo (animation-duration: 2s). Hoy la línea de tiempo puede ser el progreso del scroll mediante scroll() y view(), los gradientes interpolan con @property, y la View Transitions API morphing de vistas sin librerías externas.

1. Scroll-Driven Animations — El scroll como línea de tiempo

En una animación clásica, animation-timeline vale auto (tiempo del reloj). Con Scroll-Driven Animations, el avance de los @keyframes se vincula directamente al desplazamiento: scroll() rastrea la posición de la barra de desplazamiento y view() mide la visibilidad del elemento al cruzar el viewport.

Dos tipos de línea de tiempo y rangos de ejecución

/* 1. Barra de progreso vinculada al scroll del documento */
.progress-bar {
  animation: grow linear both;
  animation-timeline: scroll(root);
}

@keyframes grow {
  from { transform: scaleX(0); }
  to   { transform: scaleX(1); }
}

/* 2. Aparición progresiva al entrar en pantalla (sin IntersectionObserver) */
.card {
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: entry 0% cover 35%;
}

@keyframes reveal {
  from { opacity: 0; transform: translateY(24px) scale(0.97); }
  to   { opacity: 1; transform: translateY(0) scale(1); }
}
Función Timeline Qué mide Caso de uso principal
scroll(root) Progreso de scroll de toda la página Indicador de lectura superior, parallax global, cabeceras compactables
scroll(nearest) / scroll() Progreso del ancestro desplazable más cercano Contenedores con overflow: auto, carruseles horizontales
view() Intersección del propio elemento dentro del área visible Scroll reveal, tarjetas escalonadas, transiciones de entrada/salida

Control con animation-range: delimita el tramo exacto de la animación usando palabras clave de fase: entry (entrada), cover (recorrido completo), contain (totalmente visible) y exit (salida).

2. @property animada — Gradientes interpolables en GPU

Por defecto, una Custom Property (--angle: 0deg) se trata como una cadena de texto sin tipo, por lo que CSS no puede calcular valores intermedios. Al registrarla con @property y definir syntax: "<angle>", el navegador interpola cada grado dentro de conic-gradient().

Orbe cónico rotatorio y borde iluminado con @property --angle

Conic Gradient --angle: 0deg → 360deg

Tarjeta con borde cónico animado

Usa background-clip: padding-box, border-box junto a @property --angle para animar el borde sin hacks de z-index negativo.

@property --angle {
  syntax: "<angle>";
  initial-value: 0deg;
  inherits: false;
}

.gradient-card {
  border: 2px solid transparent;
  background:
    linear-gradient(#ffffff, #ffffff) padding-box,
    conic-gradient(from var(--angle), #2563eb, #7c3aed, #db2777, #2563eb) border-box;
  animation: spin-angle 4s linear infinite;
}

@keyframes spin-angle {
  to { --angle: 360deg; }
}

3. View Transitions API — Transiciones entre vistas y páginas

La View Transitions API captura una instantánea visual del estado anterior y del nuevo estado del DOM, generando pseudo-elementos (::view-transition-old() y ::view-transition-new()) que permiten interpolar posición, tamaño y opacidad entre vistas.

Dos modalidades: MPA (entre documentos) y SPA (mismo documento)

/* MODO 1 — MPA: transición automática entre páginas HTML del mismo origen */
@view-transition {
  navigation: auto;
}

/* MODO 2 — Elementos compartidos (morphing): solo 1 elemento activo con cada nombre */
.vt-view.is-active .vt-hero-img   { view-transition-name: vt-hero; }
.vt-view.is-active .vt-hero-title { view-transition-name: vt-title; }
// Disparo en SPA con degradación progresiva
if (document.startViewTransition) {
  document.startViewTransition(() => updateDOM());
} else {
  updateDOM();
}

Observa cómo la barra superior se completa al 100% del recorrido y la cabecera reduce su relleno, achica el logotipo y proyecta sombra automáticamente mediante animation-timeline: --box-scroll.

Las animaciones vinculadas al scroll eliminan los antiguos listeners window.addEventListener('scroll') que bloqueaban el hilo principal y provocaban caídas de fotogramas en dispositivos móviles.

Al combinar animation-range: 0 120px en el header y el rango completo en .progress-bar, ambos elementos reaccionan a la misma línea de tiempo con diferentes curvas de progreso.

Este patrón es ideal para barras de navegación editoriales, indicadores de progreso de lectura y galerías interactivas sin sobrecarga de JavaScript.

.vt-view.is-active .vt-hero-img   { view-transition-name: vt-hero; }

::view-transition-group(vt-hero),

  animation-duration: 420ms;
  animation-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
}
Compatibilidad y Degradación Progresiva

Encapsula siempre las reglas de Scroll-Driven Animations dentro de @supports (animation-timeline: scroll()) y verifica 'startViewTransition' in document antes de invocar la API. De este modo, los navegadores sin soporte reciben una experiencia estática funcional sin errores ni contenido oculto.
