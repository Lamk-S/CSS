# 📘 Course Notes Repository

Repositorio académico destinado a documentar, organizar y versionar los apuntes de un curso en desarrollo. Este espacio centraliza conceptos teóricos, ejemplos prácticos, ejercicios resueltos y referencias complementarias.

---

## 📌 Objetivo

Este repositorio tiene como finalidad:

- Consolidar el aprendizaje mediante documentación estructurada.
- Mantener un historial versionado del progreso del curso.
- Servir como material de consulta futura.
- Complementar clases con ejemplos prácticos y anotaciones técnicas.
- Fomentar buenas prácticas de documentación técnica.
